# Сервер x260

## Подключение

- SSH хост: `192.168.0.118`, юзер `gleb`

## Деплой

- Автоматический: push в `main` → GitHub Actions → `docker compose up --force-recreate` на x260
- Секреты (токены, ключи, прокси) хранятся в GitHub Repository Secrets и пробрасываются через workflow

## Дебаг

- Бот работает в Docker-контейнере `pesiki-bot`
- Логи: `docker logs pesiki-bot`
- Переменные окружения: `docker exec pesiki-bot printenv`

## Постоянные данные

`/app/data` подключён к внешнему Docker-тому `pesiki-bot_pesiki-data`.
Имя зафиксировано в Compose, `external: true`: том переживает checkout, пересборку,
пересоздание контейнера и `docker compose down -v`. Если том отсутствует, деплой
завершится ошибкой, вместо незаметного создания пустого хранилища.
На новом сервере сначала восстановить данные; для намеренно чистой установки
явно выполнить `docker volume create pesiki-bot_pesiki-data`.

`data/stats.sqlite` содержит APM и полный JSON разобранных матчей; `data/replay-archives`
— исходные сжатые реплеи. Ни база, ни архивы не имеют автоматического срока удаления.
Временные `.dem` удаляются после разбора. Устаревшие LLM-тексты в `data/analysis`
по-прежнему могут очищаться при смене движка; сохранённые метрики и исходники это не затрагивает.

Запрещено удалять production-том командами `docker volume rm`/`prune --all`.
Внешний том защищает от удаления через Compose, но не от явного удаления Docker-тома
или поломки диска. Резервные копии SQLite следует делать через online backup API,
а не копированием только открытого `.sqlite` без WAL.

На x260 установлен `/home/gleb/.local/bin/pesiki-stats-backup` из `tools/backup-stats.sh`.
Cron запускает его ежедневно в 04:17 по времени сервера. SQLite online backup проходит
`quick_check`, затем копируется в `/home/gleb/pesiki-backups/stats-<UTC timestamp>.sqlite`
вне Docker-тома. Права каталога 700, файлов 600. Для ручной копии запустить тот же скрипт.
Бэкап включает полные разобранные данные и APM. Исходные сжатые реплеи этим скриптом
не дублируются. Копия на том же физическом диске защищает от удаления Docker-тома,
но не от отказа диска; внешнее хранилище пока не настроено.

Контракт external volume: https://docs.docker.com/reference/compose-file/volumes/#external
