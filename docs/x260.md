## Деплой

- Автоматический: push в `main` → GitHub Actions → `docker compose up --force-recreate` на x260

## Постоянные данные

`/app/data` подключён к внешнему Docker-тому `pesiki-bot_pesiki-data`.
Имя зафиксировано в Compose, `external: true`: том переживает checkout, пересборку,
пересоздание контейнера и `docker compose down -v`. Если том отсутствует, деплой
завершится ошибкой, вместо незаметного создания пустого хранилища.
На новом сервере сначала восстановить данные; для намеренно чистой установки
явно выполнить `docker volume create pesiki-bot_pesiki-data`.

`data/stats.sqlite` содержит APM и полный JSON разобранных матчей; `data/replay-archives`
— исходные сжатые реплеи. База хранится без срока удаления. Сжатые реплеи
удаляются через 72 часа после скачивания (mtime файла): при старте бота и раз в час.
Очистка выполняется в общей очереди со скачиванием/разбором. JSON и SQLite
не удаляются; при необходимости отсутствующий архив скачивается снова, если он
ещё доступен у Valve. Старые реплеи могут быть уже недоступны для скачивания.
Офлайн backfill следует запускать на отдельной копии данных или при остановленном боте.
Временные `.dem` удаляются после разбора. Устаревшие LLM-тексты в `data/analysis`
переносятся в `data/analysis-archive` при смене движка; сохранённые метрики и исходники это не затрагивает.

Запрещено удалять production-том командами `docker volume rm`/`prune --all`.
Внешний том защищает от удаления через Compose, но не от явного удаления Docker-тома
или поломки диска. Резервные копии SQLite следует делать через online backup API,
а не копированием только открытого `.sqlite` без WAL.

На x260 установлен `/home/gleb/.local/bin/pesiki-stats-backup` из `tools/backup-stats.sh`.
Cron запускает его ежедневно в 04:17 по времени сервера. SQLite online backup проходит
`quick_check`, затем копируется в `/home/gleb/pesiki-backups/stats-<UTC timestamp>.sqlite`
вне Docker-тома. Права каталога 700, файлов 600. Для ручной копии запустить тот же скрипт.
После успешного создания и проверки новой копии `tools/rotate-stats-backups.py`
оставляет последнюю копию за каждый из 7 последних дней с бэкапами и по одной
за 4 предшествующие ISO-недели (максимум 11 автоматических копий). Ручные снимки
с другими именами не удаляются. Оба скрипта устанавливаются рядом в `~/.local/bin`.
Для предварительного просмотра: `python3 ~/.local/bin/rotate-stats-backups.py ~/pesiki-backups`.
Бэкап включает полные разобранные данные и APM. Исходные сжатые реплеи этим скриптом
не дублируются. Копия на том же физическом диске защищает от удаления Docker-тома,
но не от отказа диска; внешнее хранилище пока не настроено.

Контракт external volume: https://docs.docker.com/reference/compose-file/volumes/#external

## Эксперимент голоса voice-parity-v1

Чётный match ID выбирает прежний генератор, нечётный — короткий новый голос
(`gpt-6.1-sol`, override `OPENAI_MODEL_NEW_VOICE`). Назначение не меняется при
повторном запросе. На небольшой выборке доля не обязана быть ровно 50%.
Старый генератор формирует «НАШИ» в обеих группах; в новой заменяется только
рассказ перед этим блоком. Шапка, формат, APM и ссылка используют прежнюю обвязку.
На новом варианте это два вызова модели вместо одного.

В той же SQLite добавлены таблицы `voice_memory_*` и `voice_delivery_attempts`.
В JSON payload черновика сохраняются experiment.id, variant и model; опубликованный
текст и Telegram message ID связываются через draft_id. Отношения обновляются только
после публикации. Наблюдение чата ограничено настроенной группой и доступными боту
входящими сообщениями. Пилотная память не импортируется в production.

При неопределённом результате доставки автоматическая повторная отправка блокируется.
Перед ручным разрешением такой записи нужно сверить реальное сообщение Telegram;
не удалять блокировку вслепую. Существующий внешний том остаётся на месте.

## Диск и очистка Docker

6 ноября 2026 системный ext4-раздел расширен онлайн с LVM 100 GiB до 235,42 GiB
за счёт всего свободного места группы `ubuntu-vg`. Перед изменением выполнен
`vgcfgbackup`. Файловая система показывает около 232 GiB.

OpenClaw и его proxy-контейнер удалены, как и остановленные контейнеры прежних
разовых задач. Каталог `/opt/openclaw` (настройки и workspace, около 67 МБ) оставлен.

`tools/cleanup-docker-cache.sh` установлен как `~/.local/bin/pesiki-docker-cache-cleanup`.
Cron: воскресенье 05:43 по времени сервера. Удаляет кэш сборок старше 7 дней
с сохранением 2 GB кэша и старые dangling-образы. Не удаляет тома,
не останавливает контейнеры. Лог: `~/pesiki-backups/docker-cleanup.log`.
