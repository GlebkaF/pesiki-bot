# Общий разбор матча

`/match/:id` открывается с `#overview`. Выбор героя не меняет общий разбор, командные суммы и хронологию. `#timeline` содержит события обеих сторон, `#teams` — сравнение вклада. Старые ссылки на личные разделы сохраняются; выбор героя показывается только там. Комментарий бота о стаке остаётся в `#analysis`.

Ориентир: [Dotabuff Plus / TrueSight](https://www.dotabuff.com/plus), проверено 13 сентября 2026 года: командные сравнения урона, экономика по времени, подробные события и переход к игрокам. Здесь реализованы собственные правила, а не закрытые алгоритмы Dotabuff.

## Данные и правила

- `src/match-overview.ts` строит общий разбор детерминированно из сохранённого реплея. Открытие страницы не запускает LLM, скачивание или публикацию в чат.
- Имущество и XP суммируются только при наличии всех пяти однозначных героев каждой стороны в одной минуте. Индекс массива 0 — первая минута. Пропуски не становятся нулями и не соединяются линией.
- Максимальное отставание победителей измеряется по полным минутным снимкам. Это не поминутная вероятность победы.
- Выделяются три самых крупных непересекающихся трёхминутных окна изменения преимущества. События рядом дают контекст, но не устанавливают причинность.
- Финальное имущество отделено от последней полной минуты. Его проверочная ссылка ведёт к итоговым показателям состава.
- Боевой эпизод — временная цепочка смертей из парсера, без проверки расстояния. Повторные смерти героя учитываются отдельно. Это не гарантированно одна драка и не число уникальных погибших героев.
- Для строений включаются только башни, казармы и Древний. Сторона потерянного здания определяется по его имени. Ненадёжное поле атакующей команды не используется. Владение Roshan/Aegis не выдумывается.
- Командное сравнение урона героям использует единую разбивку combat log всех десяти участников, чтобы не смешивать частично обогащённые API-значения. Лечение союзных героев исключает самолечение и существ. Сумма установленных вардов требует подтверждённого покрытия.

## Интерфейс и ссылки

- `overviewMetric=networth|xp`, `overviewMinute=N` сохраняют просмотр графика.
- `timelineType=all|fight|building|roshan` сохраняет фильтр хронологии.
- `#moment-N` открывает конкретный эпизод, включая раскрытие и снятие несовместимого фильтра.
- `teamMetric` сохраняет показатель командного сравнения.
- `player` продолжает выбирать героя в личных разделах. Общий разбор от него не зависит.

Проверки: `npm run build`, `npm run test:insights`, `npm run test:profiles`; мобильная проверка Chromium/WebKit 320/390 px, обе темы. Тесты проверяют источники, неполные составы и минуты, нулевые значения, происхождение объектов, независимость от игрока и безопасный HTML.
